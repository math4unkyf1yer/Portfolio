Salt & Silver

Salt & Silver is a modular combat framework built in Unreal Engine 5. It features animation-driven abilities, layered combat logic, and a flexible gameplay system designed for rapid iteration and expansion.

What I Built

  • Modular ability system (UE5)
  • Animation-driven combat logic
  • State machines + gameplay tags
  • Hit detection + impact feedback
  • Enemy AI behavior trees
