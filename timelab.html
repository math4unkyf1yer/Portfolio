Time Lab

Time Lab is a first‑person puzzle game built around three core time‑manipulation abilities: Time Freeze, Object Rewind, and Positional Swap. Each puzzle is designed to teach players how to combine these abilities in creative ways to progress through increasingly complex rooms. The game focuses on clarity, readability, and player‑driven problem solving rather than combat or enemies.

What I Built

  • Modular Ability System
  • Time freeze mechanic
  • Object Rewind mechanic
  • Positional Swap Logic
  • Puzzle Framework
  • Enemy AI behavior
